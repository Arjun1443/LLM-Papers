# Large Language Model Research Reading Collection

A collection of research PDFs for studying language models, transformers, retrieval, multimodal learning, and reinforcement learning.

## Purpose

Support structured reading alongside practical AI projects. This is a reference collection, not an original model implementation or benchmark.

## Start exploring

The [LLM Papers directory](<LLM Papers>) contains the actual files. Representative topics include:

| Topic | Example material in the directory |
| --- | --- |
| Transformer foundations | Attention Is All You Need, BERT |
| Parameter-efficient adaptation | LoRA |
| Retrieval | ColBERT, RAG-related papers |
| Model architectures | Mixture of Experts, vision transformers |
| Alignment and reinforcement learning | RLHF and related material |
| Multimodal models | Vision-language and video material |

## Suggested study workflow

1. Read the abstract and identify the problem being addressed.
2. Trace the architecture and training objective.
3. Record dataset, baselines, evaluation metrics, and limitations.
4. Connect one idea to a small implementation or existing project.

Personal summaries and reproduction experiments would provide additional evidence of understanding; their presence is not implied by this collection.
